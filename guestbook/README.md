# 訪客留言板設定（Google 試算表）

留言存在你自己的 Google 試算表。訪客不用登入，填暱稱就能留言。

## 一次性設定（約 5 分鐘）

1. 打開 <https://sheets.new> 建立新試算表，命名為「N. B. Studio 訪客留言」。
2. 選單 **擴充功能 → Apps Script**。
3. 刪掉編輯器裡原本的內容，貼上 [`apps-script.gs`](apps-script.gs) 的全部內容，按 **儲存**（磁碟圖示）。
4. 右上角 **部署 → 新增部署作業**：
   - 點「選取類型」旁的齒輪，選 **網頁應用程式**
   - 執行身分：**我**
   - 誰可以存取：**所有人**
   - 按 **部署**
5. 第一次會要求授權：選你的帳號 → 出現「Google 尚未驗證這個應用程式」時按 **進階 → 前往（不安全）** → **允許**。這是你自己寫的程式，只會存取這份試算表。
6. 複製 **網頁應用程式網址**（`https://script.google.com/macros/s/…/exec`），存進 `guestbook/url.txt`，再推送到 GitHub。

## 管理留言

- **站長回覆**：在那則留言那一列的「站長回覆」欄（G 欄）打字，網站會用 N. B. Studio 的 logo 顯示為官方回覆。訪客不能用「N. B. Studio」「站長」當暱稱，所以無法冒充。
- 訪客可以回覆別人的留言，「回覆給」欄（F 欄）會記錄回覆的是哪一則留言的編號。

- 留言出現在試算表的「留言」工作表。
- 不想顯示某則：把「顯示」欄改成 `FALSE`，或刪除整列。網站下次打開留言板就會更新。
- 新留言 Email 通知：預設寄到這個 Google 帳號的 Gmail（`NOTIFY_EMAIL = 'owner'`）。改成 `''` 關閉，或填其他信箱。改程式後都要 **部署 → 管理部署作業 → 編輯 → 版本選「新版本」→ 部署**（網址不變）。
- 第一次開通通知：在編輯器上方選 `testNotify` 按 **執行**，完成寄信授權並收到測試信。
